# Сайт автозапчастин (дропшипінг)

Інтернет-магазин, що продає запчастини зі складів постачальників (Омега та інші) з вашою націнкою.
Клієнт оформлює замовлення на сайті → ви передаєте його постачальнику → постачальник відправляє
Новою Поштою напряму клієнту.

## Що вміє

**Вітрина**
- Пошук за артикулом (без різниці `W 712/75`, `w712-75`, `W71275`) і за назвою.
- Аналоги (кроси) — показуються під запитаним артикулом.
- Підбір за авто: марка → модель → група деталей.
- Кошик, оформлення: Нова Пошта (автопідказки міст і відділень, якщо задано API-ключ),
  оплата накладеним платежем або карткою через LiqPay.
- Назви постачальників клієнту не показуються — лише наявність і термін доставки.

**Адмінка** (`/admin`)
- Замовлення: статуси, ТТН, оплата, прибуток по кожному замовленню.
- Позиції замовлення згруповані по постачальниках: CSV для передачі постачальнику
  (з даними отримувача й сумою накладеного платежу) або передача через API постачальника.
- Постачальники: імпорт прайсу CSV/XLSX (колонки визначаються автоматично або задаються вручну),
  автооновлення прайсу з посилання, націнка та термін доставки для кожного.
- Правила націнки: за брендом і діапазоном цін (напр. до 500 грн — 40%, понад — 20%).
- Імпорт аналогів і таблиці підбору за авто.
- Налаштування: Нова Пошта, LiqPay, сповіщення про нові замовлення в Telegram.

## Запуск

```bash
pip install -r requirements.txt
python seed_demo.py          # демо-дані (необов'язково)
ADMIN_PASSWORD=свій_пароль SECRET_KEY=довгий_випадковий_рядок uvicorn app.main:app --port 8000
```

Сайт: http://localhost:8000, адмінка: http://localhost:8000/admin.

Docker: `docker build -t autoparts . && docker run -p 8000:8000 -v $PWD/data:/srv/data -e ADMIN_PASSWORD=... -e SECRET_KEY=... autoparts`

Змінні середовища: `ADMIN_PASSWORD`, `SECRET_KEY`, `SHOP_NAME` (назва магазину), `SHOP_DB` (шлях до БД).

## Як додати постачальника

1. Адмінка → Постачальники → «+ Додати». Код латиницею (`omega`, `elit`, `intercars`…).
2. Завантажте прайс (CSV/XLSX). Якщо колонки не розпізнались — впишіть їхні назви в картці постачальника.
3. Якщо постачальник дає постійне посилання на прайс — вкажіть у api_config `{"pricelist_url": "https://..."}`
   і натискайте «Завантажити зараз» (або налаштуйте cron на `POST /admin/suppliers/<id>/fetch`).
4. Постачальник з API: створіть клас в `app/suppliers/<код>.py` (зразок — `omega.py`) з методами
   `search()` і `place_order()` і додайте його в `ADAPTERS` у `app/suppliers/__init__.py`.

### Омега
Адаптер `app/suppliers/omega.py` підготовлений: зараз Омега працює через прайс-лист.
Коли отримаєте B2B-доступ до API Омеги (документацію, логін/ключ), допишіть у ньому `search()` і
`place_order()` — решта сайту змін не потребує.

## Підбір за авто
Повноцінна база застосовності (TecDoc) платна. Поки що таблицю можна наповнювати вручну або
з файлів постачальників: CSV `марка; модель; рік_від; рік_до; двигун; група; бренд; артикул`
(Адмінка → Каталог). Пізніше можна підключити TecDoc API.

```
app/importer.py      імпорт прайсів, аналогів, застосовності
app/suppliers/       адаптери постачальників (omega.py, base.py)
app/payments.py      LiqPay
app/novaposhta.py    Нова Пошта API

sample_data/         демо-файли (ціни вигадані)
```
